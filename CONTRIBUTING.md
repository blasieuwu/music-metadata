# repository structure

when contributing metadata files to the repository, follow this layout structure:

```text
music-metadata/repository/
└── song title - song artist/
    ├── song_title-song_artist.mdata
    └── song-title.lrc
```

## naming rules

- directory: `[song title] - [song artist]`
- `.mdata` file: `song_title-song_artist.mdata` (lowercase, spaces replaced with `_`)
- `.lrc` file: `song-title.lrc` (lowercase, spaces replaced with `-`)
